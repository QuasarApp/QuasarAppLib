Detailed Description

The Settings class base interface for implementation settings backends. Available implementations: Setting (based on QSettings backend).

Note
This is singleton object.
The all child classes should be initialized before used.
auto settingsInstance = Setting::initService<Setting>();
See also
ISettings::init method.

defaultSettings This method must be return default map of the settings and them values. If the default value argument in a getValue method will be skipped, then settings model try find a default value in this map.

settings["shareName"] = true;
settings["devSettingEnable"] = false;
settings["host"] = "";
settings["APIVersion"] = 2;
return settings;
}
