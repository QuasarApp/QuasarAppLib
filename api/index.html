QuasarAppLib

Global functions used in applications QuasarApp. This lib include include next modules:

  • Locales - This module use for parse local files. This module allows you to work with translations.
  • Params - This module use for parese app params and create log.
  • Settings - This is a module that allows you to work with application settings. It also includes the Config class - a Settings implementation that takes into account the command-line arguments that had been read.
  • Global - This module contains other global functions.

The Config class

The Config class is a Settings implementation that resolves the value of a setting with the priority: command line > config file > default value. The command line is parsed with the Params class, so all the command-line parsing logic is already implemented in the Params module.

#include <quasarapp.h>
QCoreApplication app(argc, argv);
QCoreApplication::setApplicationName("MyApp");
QCoreApplication::setOrganizationName("MyOrg");
OptionsDataList options;
options.insert("Base Options",
OptionData{{"-verbose"}, "(level 1 - 3)", "Shows debug log"});
QuasarAppUtils::Config config(argc, argv, options);
// command line > config file > default value
int level = config.getValue("verbose").toInt();

Build

  • git clone https://github.com/QuasarApp/QuasarAppLib.git
  • git submodule update –init –recursive
  • cd QuasarAppLib
  • cmake -DCMAKE_PREFIX_PATH=Your/Qt/Dir/Path .
  • make -j8
  • make test #(for testing)

Available build options:

option(QA_DISABLE_LOG "Disabled all logs (force sets verbose to 0)" OFF)
option(QA_TESTS "Enable or disable tests of the QuasarApp library" ON)

Testing

The repository contains a unit test suite based on the Qt Test framework in the QuasarAppTests/ directory (structure and naming follow the HeartTests suite of the QuasarApp/Heart repository): a single QuasarAppTest executable with per-module test classes in QuasarAppTests/units/ (Params, Settings/ISettings, Locales, OptionData, GlobalUtils).

The tests are registered with the QuasarApp CMake layer (initTests() + addTests()) and are enabled by the QA_TESTS CMake option (default ON, disabled by default on Android and iOS). To build and run the tests:

cmake -B build -G Ninja -DCMAKE_PREFIX_PATH=Your/Qt/Dir/Path
cmake --build build --parallel 8
cmake --build build --target test

The test target deploys the test executable with the CQtDeployer tool into the (git-ignored) Testing/ directory and runs it there, so the CQtDeployer tool must be installed on the build machine.

Include

The cmake build do not required Qt libraries.

  • cd yourRepo
  • git submodule add https://github.com/QuasarApp/QuasarAppLib.git # add the repository of QtBigInt into your repo like submodule
  • git submodule update –init –recursive
  • Include in your CMakeLists.txt file the main CMakeLists.txt file of QuasarAppLib library

    add_subdirectory(QuasarAppLib)

  • Rebuild your project
add_subdirectory(QuasarAppLib)
target_link_libraries(MyBinary PUBLIC QuasarApp)

Note

By Default QuasarAppLib makes as a static library. If you want to create a shared library just add the BUILD_SHARED_LIBS into your main CMakeLists.txt file. Example :

set(BUILD_SHARED_LIBS ON)
add_subdirectory(QuasarAppLib)
target_link_libraries(MyBinary PUBLIC QuasarApp)
