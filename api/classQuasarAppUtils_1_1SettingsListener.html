Detailed Description

The SettingsListener class is listener of the ISettings global object. The SettingsListener class is abstract class and contains only one method for hendling settings changes.

Example of use :

class MyClass : protected QuasarAppUtils::SettingsListener {
protected:
void handleSettingsChanged(const QString& key, const QVariant& value) override {
if (key == "shareName") {
setSessinon(static_cast<long long >(rand()) * rand());
}
}
};
