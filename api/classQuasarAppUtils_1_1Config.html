Detailed Description

The Config class.

The Config is a Settings implementation that takes into account the command-line arguments that had been read. The value of a setting is resolved with the following priority (the highest first):

  1. The value that was provided on the command line (read by the Params class).
  2. The value that is saved in the config file (the Settings backend).
  3. The default value (the def argument of the ISettings::getValue method or the ISettings::defaultSettings map).

All the command-line parsing logic is already implemented in the Params class (the Params::parseParams method), so the Config class does not use the QCommandLineParser directly.

The config file is the same file that is used by the Settings base class, so it is taken from the QCoreApplication::applicationName() and the QCoreApplication::organizationName(). They should be set before the Config object will be created.

Example of the Config usage:

int main(int argc, char* argv[]) {
QCoreApplication app(argc, argv);
QCoreApplication::setApplicationName("MyApp");
QCoreApplication::setOrganizationName("MyOrg");
OptionsDataList options;
options.insert("Base Options",
OptionData{{"-verbose"}, "(level 1 - 3)", "Shows debug log"});
options.insert("Base Options",
OptionData{{"-output"}, "(path)", "The output file"});
QuasarAppUtils::Config config(argc, argv, options);
// command line > config file > default value
int level = config.getValue("verbose").toInt();
QString file = config.getStrValue("output");
}
